Instruction Cycle Simulator

Write any program. Step through fetch, decode, execute and PC update.

Your program

One instruction per line. Registers R0 to R3, values 0 to 255, data memory addresses 0 to 15. Text after ; is a comment.

Instruction reference
MOV R1, 10Put a number or another register into R1
LOAD R1, 3R1 = data memory[3]
STORE R1, 3data memory[3] = R1
ADD R1, R2R1 = R1 + R2 (or a number)
SUB R1, R2R1 = R1 - R2 (or a number)
AND / ORBitwise, same format as ADD
HALTStop execution

Values are 8-bit. Results wrap around at 256. Flags: Z = zero, C = carry or borrow, S = top bit set.
